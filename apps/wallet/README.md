# Wallet (Ionic React)

## Run
npm run dev   # http://localhost:5173

## Tabs
- Dashboard: overview
- Citizen: profile (identity, NI, NHS, address, GP, employer)
- Credentials: verifiable credential cards
- Consents: active + history, revoke
- Activity: audit feed
- Scenarios Lab: publish demo events & raise consent requests

## Notes
- All requests for sharing appear in the Inbox banner on Dashboard; approve/deny with duration.
- No use-case switches in the wallet; scenario triggers live only in Scenarios Lab.
